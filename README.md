# TD_Migrationbridge_FE_angularjs

Standalone Angular "legacy app" frontend for the **Framework
Migration Bridge** project type — a real multi-component app (widget
list + migration-status panel, real HttpClient service), not a single
bare component.

Not connected to any backend or React app by default. The paired
standalone backend lives in `TD_Migrationbridge_BE_nodejs`, and the
new React app in `TD_Migrationbridge_FE_reactjs`. The fully connected
version lives in `TD_Migrationbridge_BE_nodejs_FE_reactjs_FE_angularjs`.

See ARCHITECTURE.txt for build commands and module layout.

Branches: one per Angular version (16, 17, 18, 19).
